## 📌 About this project

The agentic-game-factory builds mobile games from beginning to end. It creates the design, writes the code, designs the art, and composes the music. The system runs 136 tests to ensure quality. It also prepares store assets, sets up in-app purchases, and signs releases for app stores. Humans only need to approve progress at two checkpoints during the process.

This tool uses the Godot 4 engine. It includes pluggable market modules to support multiple regions. It relies on autonomous quality assurance and a database of 56 rules learned from past development failures.

## 🛠️ Step-by-step game creation

You do not need to write code to use this tool. Follow these steps to build your first game.

### 1. Define your game concept
Launch the software from your desktop icon. Select the "New Project" button. You will see a text box. Describe your game idea here. For example, describe a platformer game or a puzzle game. The AI agent analyzes your description and creates a design document.

### 2. Review the game design
The agent presents a design plan. This plan includes the game genre, the art style, and the core mechanics. Read this document carefully. You can ask the agent to change specific parts of the plan if you dislike them. Once you feel satisfied, click the "Approve" button. This is your first human gate.

### 3. Generate game components
After you approve the design, the engine starts its work. It creates the codebase in GDScript, draws sprites, and writes music tracks. You see a progress bar for each stage of development. 

### 4. Running automated tests
The factory runs 136 headless tests on your game. These tests check for bugs, performance issues, and broken links. If the agent detects an error, it attempts to fix the code automatically. The system logs every action during this phase.

### 5. Final review and polish
The agent packs all assets, sets up the store configurations, and prepares the final build. The software pauses once more before it signs the final release. Review the generated assets in the preview window. Click "Generate Signed Build" to complete the process. This is the second human gate.

## ⚙️ Managing the build process

The tool uses a modular system to ensure your game reaches the right audience. You can enable or disable specific market modules. For example, toggle the "In-App Purchase" module if you want to monetize your game. The tool handles the logic for these services automatically.

Do not restart your computer during the build process. A typical game takes between 30 and 60 minutes to complete depending on the size and complexity of your design.

## 📋 Troubleshooting common issues

* **The tool freezes:** Close the program and restart your computer. The engine includes a resume function that picks up where it left off.
* **Missing assets:** Check your internet connection. The agent downloads specific assets from centralized servers.
* **Access denied errors:** Run the software as an administrator. Right-click the shortcut and select "Run as administrator."
* **Disk space warnings:** Ensure you have enough storage before starting a build. The engine creates temporary files during the compilation of art and audio.

## 📈 Frequently asked questions

**Do I own the games built by this tool?**
Yes. All games created by this software belong to the user.

**Can I modify the code after the build?**
Yes. You can open the generated project files in the Godot 4 editor to make manual adjustments.

**Are the games ready for the app store?**
The tool prepares the files in the format required by mobile app stores. You must still submit these files via your own developer account.

**How does the AI choose the rules?**
The system references a internal database of 56 proven rules gathered from unsuccessful game development attempts. It uses these to avoid common mistakes like balancing issues or memory leaks.
